# 毕业设计答辩演示指南

## 一键进入

双击项目根目录的 `答辩演示.bat`。脚本会复用已运行的服务，或在后台启动
FastAPI，然后打开 `http://127.0.0.1:8000/#/operations`。首次进入请使用演示账号登录。
若未修改 `.env`，本地初始账号为 `admin` / `Admin123!`；正式展示前建议改为
自己的强密码。旧版单页看板保留在 `http://127.0.0.1:8000/legacy`，可作为兜底。

## 建议的 6 分钟演示流程

### 1. 系统架构（约 45 秒）

从“系统运行态势”开始，说明系统不是单次 LLM 调用，而是七段可观测链路：
需求规划、Schema 检索、SQL 生成与执行、数据治理、分析预测、报告生成、
图表渲染。先查看“答辩预检清单”，确认关键项全部通过；本地开发使用 root
账号时“数据库最小权限”会显示建议项，Docker 演示使用 SELECT-only 账号后
该项通过。指出健康状态、任务成功率、事件和检查点均来自实时 API。

### 2. 工程可靠性（约 45 秒）

展示执行模式、队列、Worker、租户配额和审计事件。说明系统支持：

- API 与 Worker 分离部署；
- 任务租约、心跳和宕机恢复；
- 幂等提交，网络重试不会重复执行；
- RBAC 与租户数据隔离；
- 跨进程共享限流；
- 持久化检查点、事件和审计记录。

### 3. 正确分析与证据链（约 80 秒）

在“对话分析”的空白对话中，点击“品类经营表现”。页面会明确显示
“固定数据集缓存 · 不调用 LLM”和“缓存演示结果”，适合网络异常时稳定展示图表、
表格、结构化报告、证据来源和 SQL；不要将它描述成实时模型输出。网络正常时再输入
“查询中国区 GMV 最高的 10 个客户”，演示
实时 Agent 进度、生成 SQL、结果表格和自动图表。强调 SQL 会经过 AST 解析、
只读白名单、结果行数和执行超时四层防护。

### 4. 多轮澄清（约 70 秒）

点击“多轮澄清与条件继承”。展示年份与国家筛选如何继承、分组维度如何替换，
以及系统在缺少 `refund_amount` 时拒绝生成净销售额。强调关键歧义会暂停或拒绝，
不会让模型自行补出口径。

### 5. 可恢复任务（约 70 秒）

点击“Worker 中断与租约接管”，展示状态从运行回到排队、Worker B 接管以及唯一
终态。再进入“任务中心”查看 Trace ID、取消入口和从头重试的重复计费告警。
说明刷新或关闭页面后仍可通过任务 ID、SSE 事件和 SQLite 检查点查看进度；当前
检查点不冒充任意节点安全续跑。

### 6. 实时路径与结论边界（约 45 秒）

网络正常时输入一个已支持问题，指出“实时 Agent 分析”标签与 SSE 节点进度。
最后说明缓存演示、真实模型小样本和历史冻结评测的边界，不能互相替代。

## 答辩常见问题提示

- **为什么使用多 Agent？** 按职责拆分规划、检索、SQL、治理、分析与报告，
  每一步都能独立校验、追踪和失败定位。
- **如何控制幻觉？** 报告只能引用当前查询产生的 EvidenceBundle，关键业务
  指标优先使用确定性 SQL 合约。
- **如何保证数据库安全？** SQLGlot AST 校验、表白名单、单语句只读限制、
  行数/超时上限和数据库 SELECT-only 账号共同生效。
- **如何支撑并发？** API 快速入队，独立 Worker 原子抢占任务；租户配额在
  SQLite 中共享，多个 API 进程不会分别超发。
- **为什么本地使用 SQLite？** 它提供零依赖可复现演示；存储接口已隔离，
  多机生产环境可替换为 PostgreSQL 或 Redis Streams。

## 现场兜底

1. 页面打不开：再次双击 `答辩演示.bat`。
2. 健康状态降级：检查 `.env`、MySQL 与 LLM 配置，再访问 `/health/ready`。
3. 网络或 LLM 不可用：点击对话页的缓存演示场景；图表运行时代码已随前端构建，
   不依赖 ECharts CDN。缓存场景必须按页面标签如实说明。
4. LLM 响应较慢：先展示“最近任务”和运行态势，再回到正在执行的任务。
5. 需要解释接口：访问 `/docs` 查看自动生成的 OpenAPI 文档。
