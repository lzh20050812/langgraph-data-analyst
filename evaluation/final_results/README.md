# Final evaluation results

This directory is the single source of truth for metrics published in the root README, thesis, and presentation.

- `final_metrics.json` contains the frozen, machine-readable headline results.
- `source_manifest.json` records the exact local source artifacts and their SHA-256 hashes.
- The frozen run date is 2026-08-12 and the source commit is `e9b8cc86dbe0cf23710f02891be4be686c0bc680`.
- The material pack recorded 32 passing tests; the current 2026-08-18 regression baseline is 55 passing tests.
- Results apply only to the checked-in data snapshot and fixed test sets. They are not open-domain claims.

The JSON files in `data/processed/` were generated by the earlier 2026-07-26 evaluation pipeline. They are retained as legacy development evidence and must not be used as the final thesis baseline.

Run the consistency guard with:

```bash
pytest -q tests/test_final_results.py
```

## Thesis chapter and figures

The final Chapter 6 draft is maintained in `docs/THESIS_CHAPTER6_FINAL.md`.
Its six figures are generated directly from the frozen JSON artifacts rather
than copied from the older development draft:

```bash
python evaluation/final_results/generate_thesis_figures.py
```

Generated images are written to `evaluation/final_results/figures/`. The
generator is deterministic for a fixed JSON pack and does not call the LLM or
database.
